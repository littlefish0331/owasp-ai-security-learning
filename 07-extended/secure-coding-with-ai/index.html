AI 輔助寫程式與模型營運安全

  • 07 延伸主題｜主題 3
  • 預估學習時間：約 70–80 分鐘（5 章閱讀約 39 分鐘；章末檢核與總測驗約 32–40 分鐘）
  • 採用來源：OWASP Cheat Sheet Series 的 Secure Coding with AI Cheat Sheet 與 Secure AI/ML Model Ops Cheat Sheet（兩份都沒有版本號；2026-10-26 讀取；GitHub 最後修改皆為 2026-10-04）

你每天用 AI 助理寫程式，助理會讀議題、裝套件、跑指令，有時還開著自動接受；寫完之後，你的團隊還要把模型訓練、存放、包成 API 上線。OWASP Cheat Sheet Series 剛好有兩份速查表各守一端：開發迴圈裡的信任邊界在哪，以及模型從訓練到執行期該怎麼營運。這個主題帶你讀這兩份，並說明哪些對應是官方寫的、哪些是本教材的整理。

學習目標

學完這個主題，你應該能：

  1. 定位與版本：說出兩份速查表各自的讀者與守的迴圈，正確標示沒有版本號的文件（讀取日加提交日）與授權，並分辨控制清單與風險清單。
    對應：第 1 章
  2. 開發迴圈的信任邊界：說出五類威脅來源，區分幻覺依賴與過期依賴的檢查時點，並判斷哪些文字會變成助理的指令。
    對應：第 2 章
  3. 工具、沙箱與規則檔：收窄助理能碰到的工具、環境與憑證，並解釋規則檔為什麼要比照 CI/CD 管線審查。
    對應：第 3 章
  4. 模型營運：把 Model Ops 九節放回生命週期，並判斷推論 API 的成本控制與執行期隔離該怎麼做。
    對應：第 4 章
  5. 跨文件整合：分辨官方寫的對應與作者整理的對應，並把開發迴圈的疏漏與營運面的控制串成一條線。
    對應：第 5 章

前置知識

  • 建議先讀 LLM Top 10 2026 主題第 3 章（供應鏈與投毒）與第 4 章（過度授權與不當輸出處理）；本主題反覆拿它們當相鄰文件。
  • 建議先看 提示詞注入防護主題（間接提示詞注入、Rule of Two）與 MCP 安全主題（工具投毒與抽換）；第 2、3 章會連到它們。
  • 第 4 章會用到 ML Top 10 主題的生命週期分組與 資料安全主題的最少日誌原則，不熟時可回頭查。
  • 資安概念若不熟，先讀 資安前置觀念（給開發者）（約 10 分鐘）。

學習路徑

  1. 第 1 章　全貌與定位兩份速查表的讀者、版本與授權的標示方式、控制清單與風險清單的差別。表 2 張、圖 1 張、題 3 題。
  2. 第 2 章　開發迴圈的信任邊界五類威脅來源；幻覺依賴與過期依賴；開發流程中的間接提示詞注入。表 3 張、圖 1 張、題 4 題。
  3. 第 3 章　工具、沙箱與規則檔把助理能碰到的東西逐項收窄；規則檔為什麼是持久化的指示來源。情境 A。表 1 張、圖 1 張、題 4 題。
  4. 第 4 章　模型營運的九節九節放回生命週期；推論 API 的成本控制；執行期與硬體隔離。表 2 張、圖 1 張、題 4 題。
  5. 第 5 章　跨文件整合與收尾其餘八節速覽；與其他 OWASP 文件的對應（官方與作者整理分欄）；一個從依賴到 API 的虛構情境 B。表 2 張、圖 1 張、題 4 題。
  6. 總測驗（15 題）涵蓋 LO1–LO5，結束時顯示各學習目標的掌握度並連回章節。
  7. 參考資料與來源核對版本與日期對照、授權、衝突與取捨、未能確認的項目。

本主題三個重點

  • 兩份速查表守不同的兩端：Secure Coding with AI 守開發迴圈（助理讀進什麼、能碰到什麼、被什麼規則檔持續影響），Secure AI/ML Model Ops 守模型的營運生命週期（訓練、成品、推論 API、部署、執行期）。
  • 它們是控制清單，不是風險分類或驗證標準；沒有版本號，引用要帶讀取日與提交日，節號也會變。
  • 兩份文件自己寫出的對應不多（Top 10 對照表與指向其他 Cheat Sheet）；與 LLM Top 10 2026 等清單的對應，本教材一律標「作者整理，非官方」。

使用說明

  • 標示 官方 的內容來自 OWASP 文件；標示 作者整理，非官方 的是本教材加的類比、歸類、對應或流程。
  • 第 3、5 章的兩個情境（A、B）都是 虛構 的公司與系統，不含可直接使用的攻擊手法；本教材也不提供任何注入文字或惡意套件範例。
  • 文件中的程式碼區塊與指令範例沒有收錄；需要時用文字描述它示範的差別。
  • Cheat Sheet 隨時會改：兩份在 2026-10-04 都還有修訂。本教材寫的是 2026-10-26 讀到的狀態。
  • 測驗進度存在你的瀏覽器 localStorage；無法使用時，進度只在本次瀏覽期間保留，閱讀與測驗不受影響。
  • 圖表以本地 Mermaid 繪製；若圖沒有顯示，每張圖下方都有文字說明。
