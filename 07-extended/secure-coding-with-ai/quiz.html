總測驗：AI 輔助寫程式與模型營運安全

  • 15 題（選擇題 6、情境判斷題 5、配對題 4）
  • 預估時間：約 18 分鐘
  • 涵蓋學習目標 LO1–LO5

情境都是虛構的公司與系統。題目只考教材教過的內容，答案與解析都能回到章節找到依據。建議先讀完第 1–5 章再作答。

怎麼作答

  • 選擇題與情境判斷題：點選一個選項，立即顯示對錯與每個選項為什麼對或不對；情境題還會附上含推理過程的參考答案。
  • 配對題：用下拉選單為每一項選類別，全部選完按「提交配對」，逐項顯示對錯與解析。
  • 成績以每題「第一次作答」計；配對題需全部配對正確才算答對。作答完畢按最下方按鈕查看成績與各學習目標掌握度。
  • 進度存在瀏覽器 localStorage；無法使用時只在本次瀏覽期間保留，不影響作答。

學習目標

  1. 定位與版本：說出兩份速查表各自的讀者與守的迴圈，正確標示版本、日期與授權，並分辨控制清單與風險清單。
  2. 開發迴圈的信任邊界：說出五類威脅來源，區分幻覺依賴與過期依賴，並判斷哪些文字會變成助理的指令。
  3. 工具、沙箱與規則檔：收窄助理能碰到的工具、環境與憑證，並解釋規則檔為什麼要比照 CI/CD 管線審查。
  4. 模型營運：把 Model Ops 九節放回生命週期，並判斷推論 API 的成本控制與執行期隔離該怎麼做。
  5. 跨文件整合：分辨官方寫的對應與作者整理的對應，並把開發迴圈的疏漏與營運面的控制串成一條線。
