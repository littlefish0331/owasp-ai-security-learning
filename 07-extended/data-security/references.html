4. 未能確認的項目

  1. DSGAI22–DSGAI26 的存在與原意：見 R-3。官方說「早期草稿中的條目因重疊被合併，編輯註記保留交叉引用」，但這與編號缺口的因果關係官方沒有說。
  2. companion 實作文件是否已發布：2026 版稱「實作最佳實務」被拆到另一份文件（正文另有「完整框架對照維護在 companion implementation guide」一句）。本教材逐頁檢查了 genai.owasp.org 資源庫的第 1–3 頁，其中與資料安全有關的只有 2026 風險文件和 2025 Best Practices 兩份，沒有看到 companion 實作指南；資源庫共 8 頁，本教材只查了前 3 頁（沿用既有主題的已知限制：後幾頁動態載入），所以「沒有看到」不等於「沒有發布」。
  3. PDF 內的 Known CVEs 與廠商事件：例如多個 CVE 編號、2025–2026 年的廠商事件（如對 Mixpanel 的揭露、Google Cloud 的蒸餾報告）。這些是文件自引的資料，本教材沒有逐項查證，教材不複述。
  4. 2025 版的版本號：PDF 內文沒有版本；封面引用格式寫 "Guide 1.0"，中繼資料檔名帶 2025。教材不寫版本號。
  5. 2025 版的「統計」欄：35%、12%、"Proof Pudding" 等，來源與可靠性未查證，不引用。
  6. 授權引用格式的筆誤：見 R-3。
  7. DSGAI10、DSGAI19 與 LLM Top 10 的對照：在附錄 A 的 DSGAI 節完全沒有出現。這是作者數出來的事實；原因官方沒說。
  8. Handbook／companion 文件／AOS 之外的 OWASP Data Security Top 10：2026 版提到「OWASP Data Security Top 10」，本教材沒有查證該清單是否存在或其現況。
