保護 Agentic 應用指南

  • 04 Agentic 與 MCP｜主題 3
  • 預估學習時間：約 60–70 分鐘（4 章閱讀約 35 分鐘；章末檢核與總測驗約 25–30 分鐘）
  • 採用來源：Securing Agentic Applications Guide Version 1.0（July 28, 2025，Status: Released）PDF；2026-10-26 讀取

前兩個主題告訴你有哪些威脅、怎麼區分它們；這個主題回答「那我要怎麼蓋」。這份 81 頁的指南把 agent 拆成六類關鍵元件，按生命週期（設計、建置、營運）列控制，再按你選的架構（單 agent、中央協調者、蜂群）與能力（API、程式碼、資料庫、網頁、PC、關鍵系統）補上對應清單，最後談驗證與部署。學完後，你能拿一個具體系統，說出它該從哪幾張清單開始。

學習目標

學完這個主題，你應該能：

  1. 定位與元件：說明指南與 T&M 的分工、範圍，並把一個 agent 拆成 KC1–KC6、指出哪些選項最放大爆炸半徑。
    對應：第 1 章
  2. 生命週期：說出設計、建置、營運三個階段各自該決定什麼，並解釋控制與資料平面分離、特權與隔離 LLM。
    對應：第 2 章
  3. 架構與能力：依架構與高風險能力，選出該先看的控制，並在預算有限時排出先後。
    對應：第 3 章
  4. 驗證與部署：說明紅隊與行為測試的角色、agent 特有的供應鏈控制，以及部署與執行期強化的重點。
    對應：第 4 章
  5. 整合：說出本指南與 T&M、Agentic Top 10、紅隊指南、AI Exchange 與 MCP 文件的關係。
    對應：第 4 章

前置知識

  • 建議先讀 Agentic 威脅與緩解（至少第 2 章的威脅分類），本指南全文用 T 編號；也可先讀 Top 10 for Agentic Applications 2026。
  • 資安概念若不熟，先讀 資安前置觀念（給開發者）（約 10 分鐘）。本主題用到攻擊面、最小權限、縱深防禦。

本主題三個重點

  • 指南是 T&M 的實作配套：T&M 說有哪些威脅，指南說怎麼在技術上實作緩解；治理與 CISO 層級指引不在範圍內。
  • 先縮小選項再補控制：記憶共享範圍、執行能力的「有限」或「廣泛」、API 模板，都直接決定被攻破後的影響。
  • 驗證不能只做靜態測試：紅隊要測提權、記憶污染與計畫操縱；CoT 不等於 agent 真正的推理。
