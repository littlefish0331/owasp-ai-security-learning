總測驗：保護 Agentic 應用指南

  • 14 題（選擇題 5、情境判斷題 4、配對題 5）
  • 預估時間：約 20 分鐘
  • 涵蓋學習目標 LO1–LO5

情境都是虛構的公司與系統。題目只考教材教過的內容，答案與解析都能回到章節找到依據。建議先讀完第 1–4 章再作答。

怎麼作答

  • 選擇題與情境判斷題：點選一個選項，立即顯示對錯與每個選項為什麼對或不對；情境題還會附上含推理過程的參考答案。
  • 配對題：用下拉選單為每一項選類別，全部選完按「提交配對」，逐項顯示對錯與解析。
  • 成績以每題「第一次作答」計；配對題需全部配對正確才算答對。作答完畢按最下方按鈕查看成績與各學習目標掌握度。
  • 進度存在瀏覽器 localStorage；無法使用時只在本次瀏覽期間保留，不影響作答。

學習目標

  1. 定位與元件：說明指南與 T&M 的分工、範圍，並把 agent 拆成 KC1–KC6、指出最放大爆炸半徑的選項。
  2. 生命週期：說出設計、建置、營運各自該決定什麼，並解釋控制與資料平面分離、特權與隔離 LLM。
  3. 架構與能力：依架構與高風險能力選出該先看的控制，並在預算有限時排出先後。
  4. 驗證與部署：說明紅隊與行為測試的角色、agent 特有的供應鏈控制，以及部署與執行期強化的重點。
  5. 整合：說出本指南與 T&M、Agentic Top 10、紅隊指南、AI Exchange 與 MCP 文件的關係。
