5.3 情境範例：審查第三方 MCP 伺服器給的執行紀錄

情境 A（虛構）：青禾物流的路線報價伺服器

虛構 青禾物流是虛構的公司。它要採購遠航雲（虛構供應者）的「路線報價」MCP 伺服器，讓公司的調度 agent 呼叫。依 MCP 主題的治理流程，這個伺服器已在試用環境跑了一輪。遠航雲交來一份簽署的執行紀錄，列出試用期間的 48 次工具呼叫，並附一個「驗證頁面」，頁面上顯示「紀錄有效」。以下為虛構，細節停在概念層級。

架構：調度 agent → 青禾自己的 MCP 閘道（會記錄穿過的呼叫）→ 遠航雲的 MCP 伺服器（遠端）→ 遠航雲的資料庫與其再下游的地圖服務。

  1. 先停在「簽章有效」之前：採購主管認為紀錄有簽章、驗證頁面也寫有效，可以直接當作試用的證據。審查員回到第 4 章：先問要確認哪個屬性，再問誰有能力偽造支撐它的證據。
  2. 逐題套用：表 5-2 列出六個問題各自得到什麼，以及分類。
  3. 決定怎麼用這份紀錄：它可以用於除錯與日常維運，不能單獨用於事件歸因或爭議。同時，因為伺服器內部看不到，青禾沿用第 2 章的限制：只給調度 agent 這個伺服器最小的工具範圍，高衝擊的下單動作留在自家的執行元件並要求綁定確切動作的批准。
  4. 對應條目：Verifying 的六個問題與工作範例；AI Agent Security 第 1 節（最小權限 (Least Privilege)）、第 4 節（批准）、第 6 節（指向 Verifying）；MCP 主題的受信任登錄與五步驟；作者整理：Agentic Top 10 的 ASI04（供應鏈）。
  5. 學到什麼：採購審查的重點不是「對方誠不誠實」，而是哪些結論可以不靠對方的誠實就成立。能自己重驗的，寫進決定；不能的，限制它能影響的範圍。
表 5-2　六個問題套用到青禾的情境（虛構；分類為依第 4 章規則的作者推演，非官方）
問題青禾手上有什麼分類（僅限所述屬性）
1 誰能寫入或改動？紀錄由遠航雲的記錄器與簽署服務產生；青禾的閘道記到穿過邊界的 52 次呼叫，與紀錄的 48 次對帳，差 4 次供應者的內部動作：供應者主張。閘道看得到的呼叫：獨立可重驗（結論是紀錄漏列 4 次，不是「全部乾淨」）
2 時間證據？紀錄內的時間戳是遠航雲寫的；之後青禾送出新的挑戰值，回傳的簽署紀錄包含相符的挑戰值時間戳：供應者主張。「簽署在挑戰之後」：獨立可重驗；各呼叫何時發生：無資訊
3 指向預期的成品與執行？預期的成品摘要值來自青禾在登錄審核時自己記下的紀錄，與簽署主體相符；執行識別碼也對上試用那一次。紀錄未提工具定義與設定是否被涵蓋成品身分與是哪次執行：獨立可重驗；摘要值與識別碼本身不回答「動作是否發生」（要靠問題 1、4 的對帳）；工具定義與設定是否涵蓋：無資訊
4 漏掉的事件看得出來？閘道的紀錄是預期事件清單的來源；遠航雲的序號只計它選擇納入的事件閘道可見範圍內：獨立可重驗；閘道看不到的內部動作：無資訊
5 記錄失敗時？青禾無法在遠航雲的環境中中斷記錄路徑；遠航雲提供文件說明會緩衝重送，沒有事故或演練證據供應者主張
6 不靠偽造能力也能驗？驗證頁面由遠航雲自己提供；簽署者憑證根在登錄審核時由青禾自行取得並設定，用維護中的驗證器在本地驗簽驗證頁面：供應者主張；本地驗簽（簽署者身分）：獨立可重驗。若改用共享祕密的 MAC：無法在持有者間歸屬作者

5.4 收尾：把兩份速查表讀成一個完整的問題

整個主題可以濃縮成兩個問句（作者整理，非官方）：agent 能做什麼？（第 2 章：限制）與發生過什麼、我怎麼知道？（第 3、4 章：看見，且第 4 章處理「紀錄不是我做的」）。第三個問句則是：這兩者本身是不是會隨變更失效？答案在第 3 章的測試與發佈閘門。三者相扣，缺任何一個，另外兩個都比看起來脆弱。

本章重點與自我檢核

  • 系列內的明寫連結：AI Agent Security → Prompt Injection Prevention、Transaction Authorization、Verifying；Verifying → Logging、MCP Security 第 7 項。與 RAG Security 沒有明寫連結。
  • 選文件先分「紀錄或服務是不是你做的」，再分「補控制、風險語言、落實或細節」。
  • 審查第三方紀錄時，同一份紀錄的不同屬性會得到不同分類；能自己重驗的寫進決定，不能的限制它能影響的範圍。
  • 後四份 AI 速查表（Secure AI Model Ops、Secure Coding with AI、AI-Powered Advertising Systems Security、AML Sanctions AI Agent Payments）本主題未涵蓋、未讀內容。
  • 給我一個 agent 安全情境，我能說出先看哪份文件。
  • 我能對一份第三方執行紀錄，逐題說出該問什麼、手上缺什麼證據。
  • 我能分辨哪些對照是文件明寫的，哪些是本教材的整理。
