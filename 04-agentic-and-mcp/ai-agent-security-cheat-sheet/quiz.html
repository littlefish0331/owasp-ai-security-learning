總測驗：AI Agent Security Cheat Sheet 與第三方執行證據驗證

  • 14 題（選擇題 5、情境判斷題 5、配對題 4）
  • 預估時間：約 21 分鐘
  • 涵蓋學習目標 LO1–LO5

情境都是虛構的公司與系統。題目只考教材教過的內容，答案與解析都能回到章節找到依據。建議先讀完第 1–5 章再作答。

怎麼作答

  • 選擇題與情境判斷題：點選一個選項，立即顯示對錯與每個選項為什麼對或不對；情境題還會附上含推理過程的參考答案。
  • 配對題：用下拉選單為每一項選類別，全部選完按「提交配對」，逐項顯示對錯與解析。
  • 成績以每題「第一次作答」計；配對題需全部配對正確才算答對。作答完畢按最下方按鈕查看成績與各學習目標掌握度。
  • 進度存在瀏覽器 localStorage；無法使用時只在本次瀏覽期間保留，不影響作答。

學習目標

  1. 全貌與定位：說出兩份 Cheat Sheet 的版本、日期與授權標示方式，區分文件明寫的連結與作者整理的對照，並把 13 項 Key Risks 當作檢查清單的起點。
  2. 限制 agent 能做什麼：用「授權在執行元件、批准綁定確切動作、失效即拒絕」檢查工具、記憶、多 agent 與資料保護的設計。
  3. 看見、驗證與測試：說明輸出驗證、監控與對抗式測試各補什麼，用濫用案例矩陣與發佈閘門檢查限制是否仍有效。
  4. 第三方執行證據：把第三方執行紀錄的屬性分成獨立可重驗、供應者主張與無資訊，並用六個問題說明理由。
  5. 整合：分辨兩份 Cheat Sheet 與系列內其他速查表、04 階段各主題的關係，依情境決定先看哪份文件。
