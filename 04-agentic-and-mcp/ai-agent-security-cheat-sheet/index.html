AI Agent Security Cheat Sheet 與第三方執行證據驗證

  • 04 Agentic 與 MCP｜主題 5
  • 預估學習時間：約 70–75 分鐘（5 章閱讀約 40 分鐘；章末檢核與總測驗約 30–35 分鐘）
  • 採用來源：OWASP Cheat Sheet Series 的 AI Agent Security Cheat Sheet（無版本號；GitHub 提交 2025-12-17 至 2026-10-04）與 Verifying Third-Party Agent Execution Evidence Cheat Sheet（無版本號；2026-10-02 至 2026-10-03）；2026-10-26 讀取

前面的 04 階段主題告訴你 agent 有哪些風險、MCP 怎麼用。這個主題換成開發者的角度：設計一個 agent 時，該先放進哪些控制？OWASP Cheat Sheet Series 的 AI Agent Security Cheat Sheet 用 13 項風險加九節最佳實務回答，另一份 Verifying Third-Party Agent Execution Evidence Cheat Sheet 則回答一個更尖銳的問題：第三方給你的執行紀錄，即使簽了章，到底能證明什麼？學完後，你能拿一個 agent 設計說出先補哪類控制，也能拿一份第三方紀錄說出哪些結論站得住、哪些只是對方的說法。

學習目標

學完這個主題，你應該能：

  1. 全貌與定位：說出兩份 Cheat Sheet 的版本／日期／授權標示方式，區分文件明寫的連結與本教材（作者整理）的對照，並把 13 項 Key Risks 當作檢查清單的起點使用。
    對應：第 1 章
  2. 限制 agent 能做什麼：用「授權在執行元件、批准綁定確切動作、失效即拒絕」檢查工具、記憶、多 agent 與資料保護的設計，找出危險做法。
    對應：第 2 章
  3. 看見、驗證與測試：說明輸出驗證、監控與對抗式測試各補什麼；用濫用案例矩陣與發佈閘門檢查限制是否仍有效。
    對應：第 3 章
  4. 第三方執行證據：把一份第三方執行紀錄的各個屬性分成獨立可重驗、供應者主張與無資訊，並用六個問題說明理由。
    對應：第 4 章
  5. 整合：分辨兩份 Cheat Sheet 與系列內其他速查表、04 階段各主題的關係，依情境決定先看哪份文件。
    對應：第 5 章

本主題三個重點

  • 九節最佳實務可以讀成兩群：限制（讓 agent 根本做不到）與看見（做了要看得到、驗得出）。兩群互相檢驗，缺一都比看起來脆弱。
  • 最關鍵的一個設計原則：agent 只提議，放行的是它碰不到的執行元件；批准要綁定確切動作並原子地消耗，旗標不夠。
  • 第三方簽章的執行紀錄，證明的是誰說的，不是說的是真的；要依屬性分成獨立可重驗、供應者主張、無資訊。
