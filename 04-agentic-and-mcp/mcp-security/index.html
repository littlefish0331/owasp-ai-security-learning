MCP 安全

  • 04 Agentic 與 MCP｜主題 4
  • 預估學習時間：約 75–85 分鐘（5 章閱讀約 39 分鐘；章末檢核與總測驗約 30–35 分鐘）
  • 採用來源：Secure MCP Server Development 指南 Version 1.0（February 2026）、第三方 MCP 使用 Cheat Sheet Version 1.0（October 23, 2025）、MCP Security Cheat Sheet（最近修改 2026-10-16）、MCP Top 10（Beta）；2026-10-26 讀取
  • NC MCP Top 10 的授權文字自相矛盾，保守視為非商業；詳見第 2 章與參考資料頁

MCP (Model Context Protocol) 把 agent 接到工具與資料，也把一個新的攻擊面接進來。OWASP 圍繞它出了四份主要文件，成熟度與讀者都不同。這個主題教你分清楚它們：你是開發者還是使用者？哪一份相對穩定、哪一份仍在 Beta？十項風險怎麼分組？官方的控制怎麼落到一個具體的伺服器或導入流程？學完後，你能拿到任一個 MCP 情境，說出該看哪份文件、先補哪類控制。

學習目標

學完這個主題，你應該能：

  1. 地圖與成熟度：說出四份主要 MCP 安全文件各自給誰、版本與日期，以及 MCP Top 10 的 Beta 狀態與 MCP06 的改名。
    對應：第 1 章
  2. 十項風險：把 MCP Top 10 依出問題的地方分組，並解釋 Tool Poisoning 與 Rug Pull。
    對應：第 2 章
  3. 開發者視角：依八類控制與最低標準檢查一個 MCP 伺服器設計，找出隔離與身分的破口。
    對應：第 3 章
  4. 使用者視角：說明受信任登錄與五步驟治理，並對第三方伺服器列出該先檢查的事項。
    對應：第 4 章
  5. 整合：決定先看哪份文件，並分辨官方明文與作者整理，說出 MCP 與 Agentic 系列的關係。
    對應：第 5 章

  • 建議先讀 Agentic 威脅與緩解（尤其 T16 與 Playbook 3）與 Top 10 for Agentic Applications 2026（尤其 ASI02、ASI04）。

本主題三個重點

  • 先分角色：開發 MCP 伺服器看開發指南；使用別人的看第三方使用 Cheat Sheet；兩者都用 MCP Security Cheat Sheet 補最新實務。
  • 成熟度不同，引用方式不同：PDF 寫版本；Cheat Sheet 寫讀取日；MCP Top 10 仍是 Beta，MCP06 已改名為 Intent Flow Subversion。
  • 多租戶的洩漏常來自三個各自合理的決定組合起來；禁止權杖直通、session 是狀態而非身分、信任有期限且可撤銷是三個反覆出現的設計原則。
