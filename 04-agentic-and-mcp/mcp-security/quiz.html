總測驗：MCP 安全

  • 16 題（選擇題 7、情境判斷題 4、配對題 5）
  • 預估時間：約 24 分鐘
  • 涵蓋學習目標 LO1–LO5

情境都是虛構的公司與系統。題目只考教材教過的內容，答案與解析都能回到章節找到依據。建議先讀完第 1–5 章再作答。

怎麼作答

  • 選擇題與情境判斷題：點選一個選項，立即顯示對錯與每個選項為什麼對或不對；情境題還會附上含推理過程的參考答案。
  • 配對題：用下拉選單為每一項選類別，全部選完按「提交配對」，逐項顯示對錯與解析。
  • 成績以每題「第一次作答」計；配對題需全部配對正確才算答對。作答完畢按最下方按鈕查看成績與各學習目標掌握度。
  • 進度存在瀏覽器 localStorage；無法使用時只在本次瀏覽期間保留，不影響作答。

學習目標

  1. 地圖與成熟度：說出四份主要 MCP 安全文件各自給誰、版本與日期，以及 MCP Top 10 的 Beta 狀態與 MCP06 的改名。
  2. 十項風險：把 MCP Top 10 依出問題的地方分組，並解釋 Tool Poisoning 與 Rug Pull。
  3. 開發者視角：依八類控制與最低標準檢查 MCP 伺服器設計，找出隔離與身分的破口。
  4. 使用者視角：說明受信任登錄與五步驟治理，並對第三方伺服器列出該先檢查的事項。
  5. 整合：決定先看哪份文件，分辨官方明文與作者整理，說出 MCP 與 Agentic 系列的關係。
