Agentic 威脅與緩解

  • 04 Agentic 與 MCP｜主題 1
  • 預估學習時間：約 60–70 分鐘（4 章閱讀約 34 分鐘；章末檢核與總測驗約 25–30 分鐘）
  • 採用來源：Agentic AI – Threats and Mitigations Version 1.1（December 2025）、Multi-Agentic system Threat Modeling Guide Version 1.0（April 2025）；2026-10-26 讀取

Agent 與一般 LLM 應用的差別，在於它會記住事情、會用工具、會自己決定下一步，還可能跟別的 agent 合作。這個主題讀的是 OWASP 給這一整類風險的「地基」：一份 17 項的威脅分類、六個對應的緩解 Playbook，以及一份教你用 MAESTRO 七層對多 agent 系統做威脅建模的指南。後面三個主題都會回頭引用它。

學習目標

學完這個主題，你應該能：

  1. 定位：說明 Agentic AI – Threats and Mitigations 的採用版本、範圍，以及 agent 比一般 LLM 應用多出的風險來源。
    對應：第 1 章
  2. 威脅分類：用 Navigator 的六個問題，為一個 agent 系統找出該優先檢視的威脅群，並說明它們如何延伸 LLM Top 10 的風險。
    對應：第 2 章
  3. 緩解策略：依症狀選出 Playbook，區分預防、反應、偵測三類措施，並在預算有限時排出先後。
    對應：第 3 章
  4. 多 Agent 威脅建模：用 MAESTRO 七層把威脅放到架構上，並知道分層與攻擊種類的差別。
    對應：第 4 章
  5. 整合：正確處理 T 編號與 LLM Top 10 編號的年份、版本與出處，並說出這個主題與其他 OWASP 文件的關係。
    對應：第 2 章、第 4 章

前置知識

  • 建議先讀 AI Exchange 第 5 章（GenAI 與 Agentic AI），了解 agent 為何把風險從「錯誤的答案」變成「錯誤的行動」；以及 GenAI Security Project 第 3 章，知道這些文件是哪個 Initiative 的產出。
  • 資安概念若不熟，先讀 資安前置觀念（給開發者）（約 10 分鐘）。本主題用到攻擊面、信任邊界、最小權限、威脅建模與預防／偵測／回應。

  3. 第 3 章　緩解策略：六個 Playbooks每個 Playbook 涵蓋的威脅與預防／反應／偵測三步；情境 A 企業 Copilot。表 2 張、圖 1 張、題 4 題。

本主題三個重點

  • 採用的是 Version 1.1（December 2025），不是調查筆記寫的 v1.0；它引用的 LLM Top 10 編號是 2025 版。
  • T1–T17 是識別碼，不是優先順序。用 Navigator 的六個問題反查，再用六個 Playbook 對策；一個事件常需疊加多個 Playbook。
  • 編號會撞號：多 Agent 威脅建模指南的 T16 以上編號與 T&M 1.1 不同，引用時要寫名稱與出處。
