第 1 章　全貌與定位

  • 預估閱讀：約 6 分鐘（不含章末檢核；另有 3 題章末檢核）
  • 對應學習目標：LO1
  • 前置：AI Exchange 第 1 章（建議先讀）

你在 AI Exchange 主題已經知道，OWASP 有兩個並列的旗艦 AI 專案。本章看另一個：OWASP GenAI Security Project。它不是一份文件，而是一個「傘」，底下有治理模型、八個工作小組，和一批持續產出的指南與工具。

1.1 一頁式全貌

表 1-1　OWASP GenAI Security Project 一頁式全貌（核對日 2026-10-26）
項目內容
是什麼全球性、社群驅動、由專家主導的開源計畫，目標是提供免費的指引與資源，協助理解與降低生成式 AI (Generative AI) 應用與導入時的資安與安全 (safety) 疑慮。範圍涵蓋 LLM、agentic AI 系統與 AI 驅動的應用。
誰發布OWASP 基金會旗下專案。官方站 genai.owasp.org；程式與文件分散在 GitHub 組織 GenAI-Security-Project。專案創辦人 Steve Wilson（官方 Initiatives 頁列為 Board Co-Chair、Project Founder）。
給誰用官方章程列出的參與對象：AI 資安研究者、工程師與從業人員；導入生成式 AI 的組織；資安專業人員、紅隊與 AI 治理專家；負責 AI 風險管理的政策制定者、監管者與合規人員。
起源2023 年 5 月以「OWASP Top 10 for LLM Application Security Project」啟動，後來擴大成包含多個工作小組與多項產出的總傘。
版本與日期沒有整體版本號：這是持續運作的專案，各產出各有版本與日期。本教材以 genai.owasp.org 與 GitHub 組織在 2026-10-26 的內容為準（GitHub 組織最後更新 2026-10-01，各儲存庫最近推送在 2026-10-23 之前）。
授權genai.owasp.org 頁尾：除非另有說明，網站內容為 CC BY-SA 4.0。各產出另有各自授權，例如 Solutions Landscape 的 PDF 封面標示 CC BY-SA 4.0。

關於規模的數字：哪些可以引用

官方介紹頁寫「截至 2024 年初，已有超過 600 位貢獻專家、18 國以上、130 家以上公司、近 8,000 位活躍社群成員」。這是當時的數字，官方自己標了時間，不能當成現況。2026 年 8–9 月的新聞稿標題另寫「社群突破 30,000 名成員」，但那是新聞稿標題，教材不把它當作可核對的統計。所以本教材不引用任何成員數字。

表 1-2　各來源對 GenAI Security Project 層級的標示（2026-10-26 實測）

未能確認：現行有效的層級

GitHub 與 AI Exchange 說旗艦；owasp.org 的 LLM Top 10 專案頁說 Lab。可能的解釋之一是「傘專案」與「LLM Top 10 子專案」在 owasp.org 上分開登記，但本教材沒有找到官方文字說明這點，所以這只是推測，不下結論。本教材描述它時用「GitHub 與 AI Exchange 稱為旗艦」，不單獨說它「是」旗艦。

AI Exchange 還給了一個使用建議：如果你想弄清楚怎麼確保 AI 系統的安全或隱私，用 AI Exchange，並由它帶你去相關的 GenAI 專案資料；如果你想快速掌握 LLM 最重要的資安疑慮，看 GenAI 專案的 LLM Top 10。

1.5 常見誤解

表 1-4　常見誤解與釐清
誤解釐清
「GenAI Security Project 就是 LLM Top 10。」LLM Top 10 只是它最早、最知名的一個產出。官方自己寫：專案起源於 Top 10，但已擴大到多個工作小組與多項專案。
「它有一個整體版本號，我可以說『GenAI Security Project v2』。」沒有。引用時要指到具體產出，並帶上該產出的版本與日期。
「它是 OWASP 的一個文件。」它是一個專案傘，有自己的治理模型與工作小組（第 2 章）。
「它的內容和 AI Exchange 重複。」範圍有重疊，但形式不同：AI Exchange 是統一的知識庫；GenAI 專案是多份獨立產出。兩者相互引用，並非複製。

本章重點與自我檢核

  • GenAI Security Project 是 OWASP 的傘專案，起源於 2023 年的 LLM Top 10，現有治理模型與八個 Initiatives。
  • 沒有整體版本號；引用要指到具體產出與其版本、日期。
  • 層級標示不一致（GitHub 與 AI Exchange 稱旗艦，owasp.org 的 LLM Top 10 登記頁稱 Lab），現行有效標示未能確認。
  • 與 AI Exchange 分工：AI Exchange 是涵蓋所有 AI 的統一知識庫；GenAI 專案是生成式 AI 領域的一組獨立產出。
  • 規模數字（成員數、國家數）官方自己標明是舊的，教材不引用。
  • 我能說出 GenAI Security Project 與 AI Exchange 的分工。
  • 我知道為什麼不能說「GenAI Security Project 的版本是 X」。
  • 我知道層級標示在不同來源不一致，並能說出是哪幾處。
