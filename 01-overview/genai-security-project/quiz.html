總測驗：GenAI Security Project

  • 15 題（選擇題 4、情境判斷題 7、配對題 4）
  • 預估時間：約 20 分鐘
  • 涵蓋學習目標 LO1–LO5

情境都是虛構的公司與系統。題目只考教材教過的內容，答案與解析都能回到章節找到依據。建議先讀完第 1–5 章再作答。

怎麼作答

  • 選擇題與情境判斷題：點選一個選項，立即顯示對錯與每個選項為什麼對或不對；情境題還會附上含推理過程的參考答案。
  • 配對題：用下拉選單為每一項選類別，全部選完按「提交配對」，逐項顯示對錯與解析。
  • 成績以每題「第一次作答」計；配對題需全部配對正確才算答對。作答完畢按最下方按鈕查看成績與各學習目標掌握度。
  • 進度存在瀏覽器 localStorage；無法使用時只在本次瀏覽期間保留，不影響作答。

學習目標

  1. 定位：說明 GenAI Security Project 是什麼、與 AI Exchange 的分工，並知道層級與版本的引用原則。
  2. 治理：說明治理模型的角色、決策與升級流程，並理解其限制。
  3. Initiatives：列出八個 Initiatives，依需求找到對應的 Initiative 與代表文件。
  4. Solutions Landscape：說明其組織方式（SecOps 九階段）與使用限制。
  5. 整合：與 AI Exchange 合用，並正確處理不同年份的編號。
