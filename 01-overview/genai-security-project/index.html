GenAI Security Project 架構

  • 01 總覽｜主題 2
  • 預估學習時間：約 60–70 分鐘（5 章閱讀約 35 分鐘；章末檢核與總測驗約 25–30 分鐘）
  • 採用來源：genai.owasp.org 與 GitHub 組織 GenAI-Security-Project，2026-10-26 讀取

這個主題帶你認識 OWASP 的另一個旗艦 AI 專案：GenAI Security Project。它不是單一份文件，而是一把傘，底下有治理模型、八個工作小組，以及一批持續產出的指南與工具。學完後，你能在面對一個 GenAI 資安需求時，知道該去哪個小組、哪份文件找答案，並知道引用時要帶哪些資訊。

學習目標

學完這個主題，你應該能：

  1. 定位：說明 GenAI Security Project 是什麼、與 AI Exchange 的分工，並知道層級與版本的引用原則。
    對應：第 1 章、第 5 章
  2. 治理：說明治理模型的角色、決策與升級流程，並理解其限制。
    對應：第 2 章
  3. Initiatives：列出八個 Initiatives，依需求找到對應的 Initiative 與代表文件。
    對應：第 3 章
  4. Solutions Landscape：說明其組織方式（SecOps 九階段）與使用限制。
    對應：第 4 章
  5. 整合：與 AI Exchange 合用，並正確處理不同年份的編號。
    對應：第 5 章

前置知識

  • 建議先讀 OWASP AI Exchange 主題，至少第 1 章（全貌與定位）。本主題會多次對照它。
  • 資安概念若不熟，先讀 資安前置觀念（給開發者）（約 10 分鐘）。本主題用到的主要是縱深防禦與生命週期的概念。

本主題三個重點

  • GenAI Security Project 是傘專案：沒有整體版本號，引用要指到具體產出並帶版本與日期。
  • 它有八個 Initiatives：Initiative 是組織方式，不是風險類別；同一個問題常橫跨多個小組。
  • Solutions Landscape 是縮小候選的起點，官方明說它「不是完整清單，也不是背書」。
