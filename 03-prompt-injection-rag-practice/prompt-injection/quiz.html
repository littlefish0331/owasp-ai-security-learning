總測驗：提示詞注入防護

  • 14 題（選擇題 4、情境判斷題 6、配對題 4）
  • 預估時間：約 20 分鐘
  • 涵蓋學習目標 LO1–LO4

情境都是虛構的公司與系統。題目只考教材教過的內容，答案與解析都能回到章節找到依據。建議先讀完第 1–4 章再作答。

怎麼作答

  • 選擇題與情境判斷題：點選一個選項，立即顯示對錯與每個選項為什麼對或不對；情境題還會附上含推理過程的參考答案。
  • 配對題：用下拉選單為每一項選類別，全部選完按「提交配對」，逐項顯示對錯與解析。
  • 成績以每題「第一次作答」計；配對題需全部配對正確才算答對。作答完畢按最下方按鈕查看成績與各學習目標掌握度。
  • 進度存在瀏覽器 localStorage；無法使用時只在本次瀏覽期間保留，不影響作答。

學習目標

  1. 為什麼沒有根治法：說明提示詞注入 (Prompt Injection) 為何沒有等價於參數化查詢 (Parameterized Query) 的做法，並用三個軸拆解情境。
  2. 防線的限制：判斷輸入篩選 (Input Screening)、結構化提示 (Structured Prompt)、輸出驗證、護欄模型 (Guardrail Model) 各自的限制與用途。
  3. 架構式控制：為有工具的 LLM 應用挑選控制，並區分降低成功率與限縮後果。
  4. 驗證與整合：設計並回報測試而不誇大，並把防禦對應到其他 OWASP 文件。
