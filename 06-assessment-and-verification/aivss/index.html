AIVSS：AI 弱點評分系統

  • 06 評估與驗證｜主題 4
  • 預估學習時間：約 50–60 分鐘（3 章閱讀約 25 分鐘；章末檢核與總測驗約 25–30 分鐘）
  • 採用來源：aivss.owasp.org、OWASP 的 AIVSS 儲存庫與 AIVSS 1.0 候選儲存庫，2026-10-26 讀取

這個主題處理「找到弱點之後，怎麼說它有多嚴重」。AIVSS (AI Vulnerability Scoring System) 想把 CVSS 的思路延伸到 AI，特別是 agentic AI。但它目前有三套說法同時存在、互相不相容。學完後，你能說明為什麼需要它、看懂 v0.8 的算式、了解 1.0 的查表方向，並避免最常見的誤用（平均分數、用小數位排名、混比不同版本的分數）。

學習目標

學完這個主題，你應該能：

  1. 為什麼與三層版本：說明為什麼 CVSS 不足以評 agentic AI 的弱點，並分辨目前並存的三套 AIVSS 說法，不把它們的分數混比。
    對應：第 1 章
  2. v0.8 計分結構：寫出 v0.8 的算式，並說明十個放大因子、威脅係數、緩解係數與嚴重度級別各自的作用。
    對應：第 2 章
  3. 1.0 查表模型：說明 1.0 參考計算器的五個 Agentic 指標、Effect Class 與 Table 6，以及它與 v0.8 的差異與自我聲明的限制。
    對應：第 3 章 3.3 節
  4. 套用、限制與解讀：用情境套用分數，正確解讀順序尺度（不平均、不以小數位排名），並知道補救重點在限縮 agent 的部署脈絡。
    對應：第 2 章 2.4 節、第 3 章

前置知識

  • 資安前置觀念（給開發者）：至少讀「風險」與「爆炸半徑」（約 10 分鐘）。
  • 知道 CVSS 是什麼最好（開發者常在套件掃描器的 CVE 旁看到它），不知道也可以，第 1 章會用一段話交代。
  • 建議讀過 OWASP AI Exchange 主題的風險與威脅概念；本主題會連到 Agentic Top 10 等文件，但不需要先讀。

同在 06 的相鄰主題（可平行閱讀）：GenAI 紅隊演練（找出並重現弱點）、AI Testing Guide（測試方法）、AISVS 與 LLMSVS（可驗證的需求）。AIVSS 負責後面的一步：排優先順序。

本主題三個重點

  • AIVSS 的核心想法是放大：agent 的自主性、工具、記憶，會把同一個技術弱點放大；所以同一個弱點在不同部署的嚴重度可以不同。
  • 「AIVSS」目前有三套說法（儲存庫通用框架、v0.8 規格、1.0 參考計算器），官方沒有說明哪一套是現行；不同版本的分數不能比較。
  • 分數是順序尺度：不平均、不以小數位排名；補救的重點常是限縮 agent 的部署脈絡，而不只是修底層弱點。
