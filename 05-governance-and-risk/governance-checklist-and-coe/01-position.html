第 1 章　全貌與定位

  • 預估閱讀：約 6 分鐘（不含章末檢核；另有 3 題章末檢核）
  • 對應學習目標：LO1
  • 前置：GenAI Security Project 第 3 章（建議先讀）

一位資安長被董事會問：「我們要導入 LLM 了，你需要先準備什麼？」他手上沒有可直接套用的範本。OWASP 的 AI Security Governance Initiative 正好為這個場景準備了兩份文件。這一章先把它們放在地圖上：各是什麼、給誰、多新，以及有哪些地方你不能照字面信。

一句話：檢核表告訴你「要想清楚哪些事」，CoE 指南告訴你「由誰、用什麼結構來持續想」。前者像導入前的盤點清單，後者像把這份清單變成常設組織的做法。

1.2 它們在 OWASP AI 資源中的位置

兩份文件都出自 GenAI Security Project 的八個 Initiatives 中的 AI Security Governance Initiative。這個 Initiative 的官方頁面（標題為 AI Security Governance and Adoption Initiative）同時列出這兩份文件、Threat Defense COMPASS 與 COMPASS RunBook，下一個主題會介紹後兩者。

未能確認：修訂史的一列日期明顯有誤

Checklist 的修訂史把 0.9「pre-release draft」寫成 2023-02-15，但它前一列 0.5 是 2023-12-06、後一列 1.0 是 2024-02-19。照順序，這一列合理的年份應是 2024，但 PDF 原文寫的是 2023，本教材不推測哪個是對的，只標示這是文件內部的矛盾。這不影響教材的任何內容。

未能確認：Checklist 是否就是「CISO Checklist」

官方介紹頁寫 2024 年 4 月發布「CISO Checklist」，資源頁寫的是 2024-05-07 的 v1.1，PDF 修訂史 v1.1 又是 2024-04-10。三個日期可以互相解釋，但官方沒有明說它們是同一份。這是 GenAI Security Project 主題已登記的未能確認項目（U-D7），本主題沿用「不下結論」的處理。

1.4 它們明說自己「不是什麼」

治理類文件最容易被誤用成「照做就合規」。兩份文件自己劃了界線，整理如下：

表 1-3　文件自己說的限制（官方，改寫）
限制原文怎麼說（改寫）你該怎麼做
不是法律意見兩份 PDF 都寫：內容不構成法律意見，僅供一般資訊用途法務條款交給法務；把檢核表當成「要問法務什麼」的清單
不是完整清單Checklist 有一節標題就是「Not Comprehensive」：它支援組織建立初期策略，但不窮盡所有使用情境與義務，組織應依自身情境與司法管轄區擴大評估把它當起點，不當終點
不背書第三方兩份 PDF 都寫：文中連到的第三方網站只為方便，OWASP 不推薦或背書其內容引用外部連結前自己評估
可依情境裁剪CoE 指南總結寫：不是每家公司都需要所有角色與功能，應依組織結構與需求調整參考它的角色表，但不必照單全收

作者整理，非官方：這兩份文件的「時間點」

兩份文件的內頁日期都落在 2024 年。它們談的是 LLM 與生成式 AI 的導入，文中完全沒有提到 MCP；Checklist 的威脅分類與部署類型也沒有 agent 這個類別。作者的判斷是：用它們時，agent 與 MCP 這類較新的範圍要自己補（可接著讀 AI Exchange 第 5 章）。這是作者對「時間點」的觀察，不是官方說法；兩份文件都沒有聲明已更新到涵蓋 agent。

1.5 常見誤解

三個容易混淆的地方

誤解
「Checklist 與 CoE Guide 是同一份文件的兩個章節。」不是。它們是兩份各自的 PDF、各自的版本與日期，只是同屬一個 Initiative。
誤解
「把檢核表全部勾完，就代表通過 OWASP 的認證。」不對。OWASP 沒有為這份檢核表提供認證，文件也明說它不窮盡。
誤解
「CoE 一定要是一個新設的部門。」文件的說法是跨部門的結構：由資安、法務、資料科學、營運的主管組成領導團隊，並依需要設工作小組；沒有要求新設一個獨立編制。

本章重點與自我檢核

  • Checklist 回答「要想清楚什麼」，CoE 指南回答「誰來做」；兩者同屬 AI Security Governance Initiative。
  • Checklist 採 v1.1（資源頁 2024-05-07）；CoE 指南採資源頁 2024-10-06，PDF 內頁寫 1.0rc。
  • 兩份文件的修訂史或版本標示都有內部不一致（0.9 的年份、1.0rc 對 v1.0），這些項目標「未能確認」。
  • 它們都明說不是法律意見、不窮盡；使用時要自己補上 agent 與 MCP 等新範圍。
  • 我能用一句話分別說明兩份文件解決的問題。
  • 我知道引用 CoE 指南時，版本要寫「PDF 內頁標示 1.0rc」而不是 1.0。
  • 我知道這兩份文件不是法律意見，也不是認證依據。
